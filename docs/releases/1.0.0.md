# Duraflow 1.0.0

## Installation and configuration

- Install with `pip install duraflow`; PostgreSQL, SQLite, and Pulsar support are
  included. The former `[postgres,pulsar]` extras remain compatible aliases.
- Configure connections explicitly with `RuntimeSettings(...)`, or load existing
  environment variables with `RuntimeSettings.from_environment(role=...)`.
- Use the public `Runtime` async context manager to initialize journals, serve an
  independent runtime role, or open a broker-only client. The CLI shares these
  connection and service factories.
- Task journal URLs, DB schemas, Pulsar tenant/namespace, secret files, and
  explicit override precedence are supported consistently in code and the CLI.
- README examples include complete environment-variable exports, Python-managed
  services, SQLite usage, and the reasons PostgreSQL is the distributed backend.
- `docker-compose/` supplies a complete PostgreSQL/Pulsar test environment with
  preconfigured connection variables, three runtime services, and an on-demand
  workflow client.

## Storage and compatibility

SQLite remains a file-backed, single-host backend using WAL and serialized
writes. PostgreSQL uses SQLAlchemy Core and database-specific locking for
concurrent distributed services. The strict `production=True` policy continues
to require verified PostgreSQL TLS for DB-backed roles and authenticated Pulsar
TLS. Broker-only roles do not require database credentials.

Version 1.0.0 uses **execution protocol 2** and **message-journal schema version 1**.
The earlier PyPI alpha's protocol-1 histories are not automatically converted.
Follow the [protocol upgrade steps](../../guide/6_operations.md#upgrading-from-protocol-1)
to drain earlier runs and initialize separate message journals. Existing
protocol-2 journals keep their schema and histories.

## Verification

Behavioral regressions cover settings precedence, role-scoped secret loading,
resource cleanup, SQLite duplicate consumption and competing outbox claims, and
workflow recovery through the public API. Native tests exercise code and
environment configuration against both SQLite/Pulsar and PostgreSQL/Pulsar.
The release workflow runs the existing qualification suite, validates wheel and
sdist metadata, installs without extras, publishes using Trusted Publishing,
and verifies PyPI distribution hashes and installation.
